# Трек Студия — личное приложение

Приватный репозиторий. Здесь собирается APK студии.

- `app/index.html` — сама студия (тот же файл открывается и в TrebEdit).
- `android/` — оболочка Android: студия внутри приложения, файлы сохраняются в «Загрузки/TrackStudio».
- `.github/workflows/android.yml` — сборка APK и проверка на эмуляторе Android 14.
- Готовый APK и результаты проверки — в ветке `builds` (`TrackStudio.apk`).

Ключ подписи лежит в `android/keystore` — поэтому репозиторий должен оставаться приватным.
Обновления ставятся поверх старой версии: данные и скачанная модель голоса сохраняются.
